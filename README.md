# 🚀  API Testing - Playwright 🧪

¡Bienvenido/a al campo de entrenamiento para llevar tus pruebas de APIs al siguiente nivel!  

Este módulo está diseñado para quienes ya conocen pruebas de APIs, pero quieren automatizarlas usando **Playwright**.

---

## 🎯 Goals

Capacitar a los participantes en la automatización de APIs, enfocándose en: manejo de requests y responses, creación de tests reutilizables y buenas prácticas.

Al final del entrenamiento, los participantes podrán:
- Configurar un proyecto para pruebas de APIs.
- Realizar peticiones HTTP y validar respuestas.
- Crear métodos reutilizables para simplificar tests complejos.
- Integrar buenas prácticas en la automatización de APIs.
- Test Data Driven y manejo de variables de entorno.

 
---
## 📚 Plan de estudio

### 👣 [Stage_1: Primer paso del ninja For Testing](/01_Stage_1/README.md)
    - Configurar un proyecto
    - Conceptos basicos de JavaScript y JSON
    - Introducción a Postman
    - Mi primera Automatización Apis.

### 👀 [Stage_2: Agudizando la visión del ninja](/02_Stage_2/README.md)
    - Estructura de carpetas en un proyecto real con Playwright.
    - Realizar flujos completos de automatización utilizando -  peticiones HTTP: `GET`, `POST`
    - Validar códigos de estado y cuerpos de respuesta `JSON`.
    - Manejar parámetros, headers y autenticación.
    - Crear métodos y utilidades para reutilizar requests comunes.

### ⚔️ [Stage_3: El dominio del ninja](/03_Stage_3/README.md)
    - Metodos http para actualizar: `PUT`, `PATCH`
    - Variables de entorno y configuración avanzada.
    - Implementar POO en la automatización de APIs. 
    - API Service Layer

### 🥷 [Stage_4: La ultima hazaña](/04_Stage_4/README.md)
    - Uso de Typescript en la automatización de APIs.
    - Interfacear con APIs usando Typescript para mejorar la robustez y mantenibilidad de las pruebas.
    - Implementar Logs durante la ejecución
    - Buenas prácticas para optimizar las pruebas API en playwright.
