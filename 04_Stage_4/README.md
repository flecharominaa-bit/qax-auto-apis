# Stage #4: La ultima hazaña 🥷

¡Bienvenido/a a la última etapa de tu entrenamiento en automatización de APIs con Playwright!
En esta estación, nos enfocaremos en llevar tus habilidades al siguiente nivel, 
explorando temas avanzados como el uso de TypeScript e implementacion de logs.  


## 🎯 Goals
- Configurar un proyecto de automatización de APIs utilizando TypeScript.
- Interfacear con APIs utilizando TypeScript para mejorar la robustez y mantenibilidad de las pruebas.
- Aprender buenas prácticas para optimizar las pruebas de APIs en Playwright.
