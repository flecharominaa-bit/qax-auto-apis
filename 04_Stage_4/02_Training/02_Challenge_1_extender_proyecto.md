# Challenge 01:  Extender proyecto utilizando servicios privados

En este reto vas a extender la arquitectura que construiste en el Exercise 01
agregando servicios privados para manejar la lógica de generación de datos de prueba.
El objetivo es mantener tus tests limpios y enfocados en la validación, delegando la creación de datos a funciones especializadas que pueden ser reutilizadas en múltiples tests.

---

## Servicios privados y Data Builders

### Realizar pruebas en el servicio de Collections
Servicio: https://api.restful-api.dev/collections
Headers: `x-api-key` `<your_api_key>`

### Implementar data builders para generar payloads de prueba

Para la creacion de productos en el servicio de Collections, implementa funciones que generen payloads con datos aleatorios o predefinidos. 
Esto te permitirá crear productos de prueba de manera rápida y consistente en tus tests.
