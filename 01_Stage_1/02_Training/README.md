# Training #1: Automatización de APIs con Playwright 🚀✨

En este entrenamiento, el aprendiz aprendera a automatizar pruebas de APIs partiendo de una historia de usuario, creando casos de prueba y validándolos tanto manualmente 
en **Postman** como pasar a escribir nuestro test automatizados usando **Playwright**.

## 🎯 Goals
- Crear tests básicos para APIs, realizando peticiones HTTP y validaciones de respuestas.
- Configurar una historia de usuario con criterios de aceptación y casos de prueba.
- Probar endpoints manualmente usando **Postman** antes de automatizarlos.
- Implementar pruebas automatizadas.
- Resolver ejercicios prácticos que integren todo lo aprendido en un flujo real de pruebas.
