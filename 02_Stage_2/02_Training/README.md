# Training #2: Creación de un proyecto real 

En este entrenamiento pondremos las manos en el código.
Aprenderás a desarrollar funciones JavaScript reutilizables para simplificar tus pruebas de APIs con **Playwright**,
manejar variables dinámicas para inyectar *Tokens* de seguridad, y estructurar datos de prueba.

Además, validaremos a profundidad respuestas JSON, códigos de estado y *headers*. Todo esto organizando tu proyecto con una estructura de carpetas profesional, aplicando las mejores prácticas de la industria para que tus casos de prueba sean escalables y fáciles de mantener.

## Goals
- Desarrollar funciones JS (helpers/utils) reutilizables para simplificar la automatización de peticiones.
- Definir y gestionar variables dinámicas para atrapar tokens y generar datos únicos.
- Validar aserciones complejas en respuestas JSON, códigos de estado y cabeceras (headers).
- Organizar un proyecto en Playwright con la estructura de carpetas recomendada por los expertos.
- Aplicar buenas prácticas en la escritura, legibilidad y mantenimiento de casos de prueba.
