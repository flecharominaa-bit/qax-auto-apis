# Stage #3: El dominio del ninja ⚔️

En este stage darás un salto hacia el **pensamiento profesional en automatización de pruebas de APIs**, 
entendiendo cómo llevar tus pruebas a un nivel más estructurado, escalable y realista.


## 🎯 Goals

- Comprender y aplicar métodos de actualización de datos (`PUT` y `PATCH`)
- Implementar Programacion orientadas a objetos (POO) para organizar y reutilizar código en pruebas de APIs.
- Implmentar Api Service Layer para separar la lógica de las pruebas de la interacción con la API.
- Configurar entornos y variables dinámicas
