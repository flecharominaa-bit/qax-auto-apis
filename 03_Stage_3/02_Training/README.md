# Training #3: Implementaciones avanzadas en API Testing con Playwright ✨

En este entrenamiento llevarás tus habilidades en Playwright al siguiente nivel.
Aprenderás a organizar tu proyecto con una arquitectura profesional usando **modelos POO**
para serializar y deserializar requests y responses, implementar un **API Service Layer**
para centralizar tus llamadas HTTP, configurar **variables de entorno** para múltiples ambientes,
y documentar tus tests con **anotaciones** que los hacen legibles y mantenibles.

Todo esto aplicado sobre flujos reales con los métodos `PUT` y `PATCH`.

---

## 🎯 Goals

- Estructurar un proyecto Playwright con arquitectura profesional desde cero.
- Crear modelos de Request y Response usando clases de JavaScript (POO).
- Implementar un API Service Layer que centralice y reutilice los requests HTTP.
- Configurar variables de entorno con `.env` para separar ambientes de ejecución.
- Utilizar anotaciones de Playwright (`describe`, `step`, `skip`, `tag`) para organizar y documentar tests.
- Aplicar métodos `PUT` y `PATCH` para actualizar recursos y validar sus respuestas.
- Fortalecer buenas prácticas de estructuración y mantenimiento de pruebas API.
